# HistoLoop

**Human-in-the-Loop Histopathology Annotation Platform**

An interactive web application for viewing whole-slide images, reviewing kidney cortex/medulla predictions, and recording human corrections.

- [Setup, data formats, screenshots and quick start](SVC_GPU/human_loop/README.md)
- [Architecture](SVC_GPU/human_loop/ARCHITECTURE.md)
- [Executed validation and deployment limits](SVC_GPU/human_loop/docs/validation.md)

![HistoLoop with synthetic demonstration data](SVC_GPU/human_loop/docs/screenshots/main-interface.png)

The existing research code and history are preserved. HistoLoop uses the internal `SVC_GPU.human_loop` package. Research datasets and checkpoints are not distributed.
